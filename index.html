1. Privacy Policy

This Privacy Policy explains how the publisher of WA Box: Status Saver & Tools (“WA Box”, “we”, “us”) handles information when you use the Android application identified as package com.wabox.status.saver.tools.

WA Box is designed to run on your device. We do not require you to create a WA Box account. We do not operate a WA Box chat server that stores your conversations.

1.1 What the app does

WA Box provides on-device tools related to messaging utilities, including:

  • Direct Chat by phone number
  • Status Saver
  • Optional message recovery from notifications you already received
  • In-app WhatsApp Web / multi-profile web sessions
  • Chat tools (speech-to-text, fancy fonts, text tools)
  • Media tools (compressor, enhancer, background remover, GIF, PDF tools)
  • Scheduler and message repeater
  • Cleaner for WhatsApp media already on the device
  • Auto reply (optional)
  • App lock (PIN stored on the device)
  • Overlay / popup-ad detector

1.3 Permissions

Android may show permission prompts. You can deny a permission; the related feature will not work until you allow it.

  • Internet — open WhatsApp / wa.me links and load official WhatsApp Web.
  • Microphone — speech-to-text.
  • Photos / videos / audio / storage — Status Saver, Cleaner, compressor, PDF/GIF/enhancer, and similar tools.
  • Contacts — pick a number from your address book when you choose to.
  • Notifications (post) — remind you about scheduled sends and recovery alerts.
  • Notification access (optional) — Message Recovery and Auto Reply copy notifications already shown on this phone. This does not decrypt WhatsApp’s private database.
  • Accessibility (optional) — after you enable it, WA Box may tap Send in WhatsApp for scheduled or repeated messages you started. It is not used to read your screen for advertising.
  • Exact alarms / battery exceptions (optional) — fire scheduled messages on time.
  • Full-screen intent / vibration / boot completed / foreground service — wake a scheduled “Send now” screen when the phone is locked or the app is in the background.
